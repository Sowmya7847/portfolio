# Sowmya Jeedigunta - Portfolio Website

A personal portfolio built with React, TypeScript, Tailwind CSS, and Three.js featuring interactive 3D digital artifacts.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Sowmya7847/portfolio)

## Features
- **3D Digital Artifacts Hero Scene**: Custom WebGL interactive crystal, floating glass cubes, and microchip components built with Three.js.
- **Responsive Layout**: Designed with Tailwind CSS with custom styling and animations.
- **Single Page Application**: Configured for continuous deployment on Render.

## Deployment on Render
Click the button above or:
1. Go to [Render Dashboard](https://dashboard.render.com/).
2. Select **New +** -> **Blueprint** or **Static Site**.
3. Connect https://github.com/Sowmya7847/portfolio.
4. Deploy!
